# AA Annotate v0.4.0

Cross-platform foundation, plugin packaging, capture scaling, and completion safety release.

## Added

- Added shared platform abstractions so the app can run with platform-specific capture and window integration services.
- Added first-class Codex and Claude plugin metadata to the packaged bundle.
- Added per-capture export scale controls with live previews.
- Added `--default-scale` for agent-launched sessions so callers can choose the starting scale for new captures.
- Added `--caller` app mode so agent handoff and standalone human export flows can behave differently.
- Added an export destination picker for standalone human launches.
- Added a confirmation dialog before finishing, sending, or exporting an annotation session.

## Changed

- Moved export scaling from a session-wide toolbar control to an independent capture scale selector.
- Preserve each capture's selected scale independently during export.
- Updated bundled skill guidance to choose default capture scale based on expected readability needs.
- Package version metadata is now centralized for app, assembly, plugin, and Windows package outputs.
- Keep plugin installation metadata in sync across Codex and Claude plugin bundles.

## Fixed

- Prevent accidental early completion by requiring explicit confirmation before the final handoff.
- Avoid deleting scaled preview files as raw private capture sources during cleanup.
- Keep scaled previews and overlay masks aligned while switching captures or scale settings.
- Improve CLI launch arguments so agent sessions preserve automatic handoff behavior.
