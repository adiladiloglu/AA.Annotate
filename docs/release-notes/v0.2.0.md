# AA Annotate v0.2.0

Privacy and export-size release for the Windows annotation overlay and agent handoff artifacts.

## Changed

- Added privacy masks that redact selected regions in exported capture images.
- Render privacy masks as black rectangles labeled `Privacy mask`.
- Apply privacy masks before annotated overview images and annotation crop images are generated.
- Annotation boxes and privacy masks can be resized from every side and corner.
- Resize handles appear only while the annotation box or privacy mask is selected, dragged, or resized.
- Selected annotations and privacy masks are raised above overlapping boxes while editing.
- Privacy masks use a stronger redaction opacity and a more inset close button.
- Added export image scaling from 20% to 100%, including 100%, 75%, 66%, 50%, 33%, and 25% presets.
- Export annotation coordinates and annotation snippets in the same scaled coordinate space as the exported primary image.
- Keep final exports separate from private working session files for every session.
- Updated the bundled Codex skill to treat masked/scaled exported images as the primary source of truth.

## Fixed

- Prevented privacy-masked regions from appearing unmasked in annotated overview images and annotation crop images.
- Prevented final export folders from being reused as live working session folders.
- Fixed selection cycling across overlapping privacy masks and annotation boxes.
- Fixed cropped captures blocking pass-through input after crop editing was closed.
- Fixed first annotation comment focus so typing can start immediately.
